#  Diagramas UML del Proyecto UMBRAL

En esta carpeta se almacenan los **diagramas UML** del sistema *UMBRAL COFFE*, correspondientes a las fases de análisis y diseño del proyecto.

## 📂 Contenido
- **Diagrama General:** muestra la interacción de todos los perfiles con el sistema.
- **Perfil Administrador:** casos de uso de gestión de usuarios, productos y reportes.
- **Perfil Cliente:** casos de uso relacionados con la compra, calificación y registro.
- **Perfil Personal de Inventarios/Auxiliar:** casos de uso de control de inventario y estatus de pedidos.

Los diagramas están disponibles en formato **PNG** para visualización directa.
